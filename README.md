# Piazza di Mare

Sitio oficial de **Piazza di Mare** — confitería, café y gastronomía frente al mar en Mar del Plata.

## Dirección visual aprobada

Concepto premium costero basado en:
- arquitectura contemporánea con grandes paños de vidrio;
- relación protagonista con el mar;
- paleta azul profundo, crema y dorado;
- fotografía cálida de golden hour;
- café de especialidad, pastelería, desayunos, almuerzos y atardeceres;
- tono editorial y aspiracional;
- experiencia pensada para vender Piazza di Mare como destino, no sólo como cafetería.

## Stack

- React
- Vite
- TypeScript
- Sitio estático compilado a `dist/`

## Deploy

Rama de desarrollo visual actual: `feature/premium-v1`.

Objetivo de publicación: Hostinger conectado a GitHub. Una vez aprobada la versión visual y técnica, `main` será la rama canónica de producción.
